۱.  معرفی پروژه
این برنامه برای ثبت و مدیریت هزینه‌ها و درآمدهای روزانه طراحی می‌شود تا کاربران بتوانند مخارج خود را پیگیری کنند و از وضعیت مالی خود اطلاع داشته باشند.
۲. مسئله و نیازی که پروژه حل می‌کند
بسیاری از افراد هزینه‌های روزانه خود را یادداشت نمی‌کنند و در پایان ماه نمی‌دانند پولشان را برای چه چیزهایی خرج کرده‌اند. این برنامه به آن‌ها کمک می‌کند هزینه‌ها را ثبت کنند و مخارجشان را بهتر مدیریت کنند.
